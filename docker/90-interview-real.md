# Docker 真实/高频面试题汇编

> 问法贴近国内互联网与社区 2024–2025 高频汇总；**不编造具体公司署名**。答案可与 `10/20/30` 交叉，此处按「面试现场口述」写法。  
> 参考倾向：国内大厂容器/运维面流程题、社区高级原理题（Namespace/cgroup/overlay/BuildKit）、Compose 生产实践题。

### R1. 请解释 Docker 容器和虚拟机的区别，并说明容器的隔离是如何实现的？

- **难度**: mid
- **标签**: 原理
- **来源倾向**: 大厂基础必问

**答案**

容器共享宿主内核，VM 有独立 Guest OS。隔离主要靠 **Namespace**（看得到什么）和 **cgroup**（能用多少），再加文件系统联合挂载、capabilities/seccomp 等。  
详见 [20-mid-qa Q8/Q9](20-mid-qa.md)、[30-senior-qa Q5](30-senior-qa.md)。

**口述模板（30–60 秒）**

1. 共享内核 vs 独立内核。  
2. Namespace + cgroup 是核心。  
3. 隔离弱于 VM，需加固。  
4. 可追问：user ns / privileged。

**常见追问**

- 容器逃逸和内核漏洞关系？→ 共享内核意味着宿主补丁至关重要。

### R2. `docker run` 背后发生了什么？

- **难度**: senior
- **标签**: 运行时
- **来源倾向**: 高级/专家面

**答案**

CLI → dockerd →（pull）→ 创建可写层与配置 → containerd → runc 建 ns/cgroup/rootfs → exec 进程 → shim 托管。  
详见 [20-mid-qa Q7](20-mid-qa.md)、[30-senior-qa Q1](30-senior-qa.md)。

**口述模板（30–60 秒）**

1. 高层 API 到 OCI 运行时逐层下沉。  
2. 隔离与配额在启动时装配。  
3. runc 一次性，shim 常驻。  
4. 可追问：与 CRI 关系。

**常见追问**

- dockerd 挂了容器还在吗？→ 看 live-restore 与版本配置。

### R3. 镜像分层与构建缓存失效规则？如何写才能快？

- **难度**: mid
- **标签**: 构建
- **来源倾向**: 后端/DevOps 高频

**答案**

层缓存按指令输入命中；变则后续全失效。依赖安装放前，源码 COPY 放后；用多阶段与 BuildKit cache mount。  
详见 [20-mid-qa Q1/Q4/Q5](20-mid-qa.md)。

**口述模板（30–60 秒）**

1. 缓存失效会连锁。  
2. 稳定层靠前。  
3. BuildKit 缓存挂载加速且不脏镜像。  
4. 可追问：CI 远程缓存。

**常见追问**

- 为什么官方建议 `apt-get update && install` 同一 RUN？→ 一致性与层卫生。

### R6. Volume 和 Bind Mount 区别？生产怎么选？

- **难度**: mid
- **标签**: 存储
- **来源倾向**: 高频基础

**答案**

Volume 由 Docker 管理，可移植性更好；Bind 绑宿主路径，适合开发。生产持久化优先 Volume/外部盘，开发常用 Bind。  
详见 [20-mid-qa Q17](20-mid-qa.md)。

**口述模板（30–60 秒）**

1. 管理方不同。  
2. 生产 volume，开发 bind。  
3. 数据别放可写层。  
4. 可追问：权限与 SELinux。

**常见追问**

- compose down 删不删卷？→ 默认不删，`-v` 才删。

### R7. Docker 默认 bridge 和自定义 bridge 有什么区别？为什么生产要用自定义？

- **难度**: mid
- **标签**: 网络
- **来源倾向**: 网络专项高频

**答案**

自定义 bridge 提供嵌入式 DNS，可用容器名通信，隔离与管控更好；默认 bridge 服务发现弱、历史包袱多。Compose 默认建项目网络。  
详见 [20-mid-qa Q12](20-mid-qa.md)。

**口述模板（30–60 秒）**

1. 关键差异是 DNS 服务发现。  
2. 生产/多容器必自定义网络。  
3. 别用过时 link。  
4. 可追问：跨主机 overlay。

**常见追问**

- 端口映射原理？→ NAT/DNAT，见 [20-mid-qa Q13](20-mid-qa.md)。

### R9. 容器启动后立刻退出，如何排查？退出码 137、139？

- **难度**: mid
- **标签**: 排障
- **来源倾向**: 运维面高频

**答案**

ps -a → logs → inspect（OOMKilled）→ 命令/环境 → 交互复现。137 常 SIGKILL/OOM；139 常 SIGSEGV。  
详见 [20-mid-qa Q11/Q28](20-mid-qa.md)，命令序列 [40-coding H7](40-coding-handwritten.md)。

**口述模板（30–60 秒）**

1. 状态日志优先。  
2. 137 看内存，139 看崩溃。  
3. 复现时关掉疯狂重启。  
4. 可追问：宿主 dmesg。

**常见追问**

- 前台正常后台退出？→ 进程 daemon 化导致 PID1 结束。

### R10. 如何限制容器资源？内存超限会发生什么？

- **难度**: mid
- **标签**: cgroup
- **来源倾向**: 高频

**答案**

`--memory`/`--cpus`/`--pids-limit` 等落入 cgroup。超内存常被 OOM Kill。生产必须设 limit 并监控。  
详见 [20-mid-qa Q9](20-mid-qa.md)、[30-senior-qa Q3](30-senior-qa.md)。

**口述模板（30–60 秒）**

1. cgroup 强制配额。  
2. 内存超限可能 137。  
3. 还要防 PID/磁盘。  
4. 可追问：cpu throttle。

**常见追问**

- 只限制 cpu-shares 够吗？→ 那是相对权重，忙时才体现，不等于硬上限。

### R12. 为什么不要在镜像里放密钥？已经放了怎么办？

- **难度**: mid
- **标签**: 安全
- **来源倾向**: 安全加分题

**答案**

层历史可恢复；删除文件不等于删除层中秘密。视为泄露：轮换、重建、清理仓库。构建用 secret mount，运行时注入。  
详见 [20-mid-qa Q24](20-mid-qa.md)。

**口述模板（30–60 秒）**

1. 镜像层可被导出分析。  
2. 按泄露流程处置。  
3. 工具链上杜绝再进层。  
4. 可追问：扫描能否发现所有密钥。

**常见追问**

- 多阶段 COPY 会不会把密钥带过？→ 会，若你从含密钥阶段拷贝了错误文件。

4. 可追问：grace period。

**常见追问**

- 僵尸进程怎么来？→ 子进程退出未被 wait。

### R29. Docker Desktop / 非 Linux 上跑容器的本质？

- **难度**: junior
- **标签**: 基础
- **来源倾向**: 易忽略基础题

2. 桌面靠 VM。

**常见追问**

### R31. 如何在不改业务代码的前提下尽量缩小镜像、减少攻击面？

### R32. 连接跟踪打满、偶发连接失败，你怎么想到 Docker？

- **难度**: senior
- **标签**: 网络, 性能
- **来源倾向**: 高级排障

**答案**

高密度 NAT 发布导致 conntrack 压力；结合宿主指标与发布窗口验证；提高上限、减暴露、改数据路径。  
详见 [30-senior-qa Q11](30-senior-qa.md)。

**口述模板（30–60 秒）**

1. 从偶发联想到内核连接表。  
2. 对照 Docker NAT 模型。  
3. 治理暴露与容量。  
4. 可追问：kube-proxy 模式。

**常见追问**

- 如何快速确认？→ 看 `nf_conntrack_count` 与失败时间相关性。
