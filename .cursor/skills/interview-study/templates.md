## 通用 Q&A 题（`10/20/30`、`90`）

```markdown
### Q1. 什么是 Virtual DOM？和真实 DOM 的关系？

- **难度**: mid
- **标签**: 渲染, Virtual DOM

**答案**

Virtual DOM（虚拟 DOM）是用 JS 对象描述 UI 的树形结构……
首次出现术语可写：Reconciliation（协调）指……

**口述模板（30–60 秒）**

1. 一句话结论：VDOM 是 UI 的 JS 描述，用来算差异再最小更新真实 DOM。
2. 关键机制：render → VDOM 树 → diff → commit 到真实 DOM。
3. 对比/注意：不是一定更快，价值在可预测更新与跨平台抽象。
4. 可追问：React 18 的并发与 lanes 可再展开。

**常见追问**

- Diff 复杂度？→ 同层比较、key 的意义…
- 没有 VDOM 行不行？→ 如 Svelte 编译期、直接命令式…
```

## 主题自适应提示

| 主题类型 | 10/20/30 侧重 | 40 手写 | 50 设计 |
|----------|---------------|---------|---------|
| 前端框架 | 渲染、状态、性能、工程化 | Hooks/工具函数/组件 | 大型应用拆分、性能、微前端 |
| 后端/语言 | 并发、内存、网络、存储 | 算法变形、API 设计 | 服务拆分、一致性、限流 |
| 容器/DevOps | 隔离、网络、存储、编排 | Dockerfile/排障 | 发布、可观测、多环境 |
| 中间件 | 模型、持久化、副本、积压 | 配置与排障脚本思路 | 选型与容量、容灾 |
